Page LayOut>>>
		Page Layout kya hota hai? (Simple Definition)
		Page Layout ek "Design ya Naksha" (Blueprint) ki tarah hai. Jab tu Salesforce mein kisi object ka koi record (jaise Position record) kholta hai, 
		toh screen par jo fields, buttons, related lists aur sections dikhte hain—wo sab Page Layout hi tay karta hai.

3. अगर आप Junction Object में से किसी एक Master-Detail FIELD को डिलीट करते हैं:

• रिलेशनशिप का प्रकार बदल जाएगा: चूंकि Junction Object दो Master-Detail फ़ील्ड्स से मिलकर बनता है, अगर आप उनमें से एक Master-Detail फ़ील्ड को डिलीट कर देते हैं, तो वह ऑब्जेक्ट अब Junction Object नहीं रहेगा।
• One-to-Many (1:M) में बदलाव: अब वह ऑब्जेक्ट सिर्फ एक ही Parent से जुड़ा रहेगा और एक सामान्य Child Object की तरह व्यवहार करने लगेगा। डिलीट की गई फ़ील्ड का सारा डेटा हमेशा के लिए साफ हो जाएगा।


4. अगर आप पूरा Junction Object ही डिलीट कर देते हैं:

• सारे लिंक्स और डेटा खत्म: Junction Object, उसके सारे रिकॉर्ड्स, पेज लेआउट्स और दोनों Master-Detail फ़ील्ड्स डिलीट हो जाएंगे और Recycle Bin (Deleted Objects) में चले जाएंगे।
• दोनों Parents सुरक्षित: Parent A और Parent B को कोई नुकसान नहीं होगा, लेकिन उनके बीच का Many-to-Many पुल (Bridge) पूरी तरह टूट जाएगा।


5. अगर आप पूरे Parent Object (A या B) को डिलीट करना चाहें:

• Salesforce सीधे डिलीट नहीं करने देगा (Blocked): चूंकि Junction Object इन दोनों Parents पर निर्भर है, इसलिए Salesforce आपको किसी भी Parent Object को सीधे डिलीट करने से रोक देगा।
• डिलीट करने का तरीका: पहले आपको Junction Object पर जाकर उस विशेष Parent से जुड़ी Master-Detail Relationship Field को डिलीट करना होगा, उसके बाद ही आप मुख्य Parent Object को डिलीट कर पाएंगे।


   
6>
1. Primary vs Secondary Parent: Junction Object पर जो Master-Detail फ़ील्ड सबसे पहले बनाई जाती है, वह Primary Parent कहलाती है। जो दूसरी बार बनाई जाती है, वह Secondary Parent होती है।
2. Look & Feel (Look and Feel Inherit): Junction Object के रिकॉर्ड का बैकग्राउंड कलर, ओनर (Owner) और लुक हमेशा Primary Parent के जैसा ही तय होता है।
3. Roll-up Summary: आप दोनों Parents (A और B) के ऊपर Roll-up Summary Fields बना सकते हैं ताकि यह गिना (Count/Sum) जा सके कि एक Parent से कितने Junction रिकॉर्ड्स जुड़े हुए हैं।
